읽고 이해한 것과 **남에게 설명할 수 있는 것**은 다릅니다. 배운 내용을 문장으로 다시 쓰면 구멍이 어디인지 드러납니다. 그래서 이 기록장은 발행용이 아니라 **복습용**입니다.

## 무엇을 적는가

- 언어별 학습 기록 (Go, Rust, Python, TypeScript)
- 개념 정리 — 헷갈리는 지점을 예제로 다시 확인한 것
- 실험 기록 — 코드를 돌려 보고 관찰한 것
- 트러블슈팅 — 막혔다가 푼 과정
- 회고 — 프로젝트가 끝난 뒤 남는 생각

## 어떻게 적는가

글마다 세 가지만 남깁니다.

| 항목 | 기준 |
| --- | --- |
| 왜 봤나 | 문제 상황 또는 궁금증 |
| 무엇을 알았나 | 근거와 예제가 있는 결론 |
| 다시 볼 것 | 다음에 또 헷갈릴 부분 |

## 글 파일 만들기

새 글은 제목과 언어, 태그를 지정해 만듭니다.

```yaml title="src/content/posts/example.mdx" hl={7} numbers
---
title: "글 제목"
date: 2026-09-10T21:00:00+09:00
languages: ["go"]
tags: ["슬라이스"]
---
```

작성 중인 글은 `draft: true`로 두고, 확인을 마치면 값을 제거하거나 `false`로 바꿉니다.

> 처음부터 잘 쓰려고 하지 않기로 했습니다. 다듬는 대신 계속 쌓는 쪽을 택했습니다.
