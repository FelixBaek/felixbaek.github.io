## 언제 쓰나

- 문서만으로는 동작이 확실하지 않을 때
- 성능·메모리 같은 관찰 가능한 값을 비교할 때
- "이렇게 하면 될 것 같은데" 를 검증할 때

## 남기는 형식

| 항목 | 내용 |
| --- | --- |
| 가설 | 그렇게 될 것이라고 본 이유 |
| 방법 | 최소 재현 코드, 도구 버전 |
| 관찰 | 실제 출력·수치 |
| 해석 | 가설이 맞았는지, 왜 그런지 |

브라우저에서 확인할 수 있는 실험은 **글 안에 Wasm 모듈로 심어 둡니다.** 독자가 같은 값을 직접 만들어 볼 수 있어야 기록으로서 완성됩니다.
